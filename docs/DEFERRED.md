# Deferred

These are directions that may make sense later, but are not part of the current product commitment.

## Moderation and admin tooling

Not built yet:
- report flows
- hide/remove comment tools
- photo moderation queue
- admin dashboards
- admin-only store/item edit-delete tools

Direction:
- this is no longer just a vague maybe
- some lightweight moderation/admin layer is now expected

## Store and item deduplication workflow

Not built yet:
- merge duplicate stores
- merge duplicate items
- review queue for near-matches

## OCR or image-assisted extraction

Not built yet:
- parse text from photos
- auto-fill price/package from image

## Barcode or SKU intelligence

Not built yet:
- barcode scanning
- SKU-level identity
- brand/variant reconciliation

## Chain-level analytics

Not built yet:
- aggregate chain views
- chain-wide cheapest/latest logic

Likely future role:
- supplement exact-store pages, not replace them

## Item taxonomy / hierarchy

Not built yet:
- category -> family -> item hierarchy
- tag system for items
- hybrid hierarchy-plus-tags browsing/filtering

Likely future role:
- help make canonical items less flat and less confusing as the catalog grows

## Reputation or trust systems

Not built yet:
- weighted votes
- user reliability score
- submission trust score

## Saved filters / subscriptions / alerts

Not built yet:
- notify me when an item drops below X
- saved compare searches
- watchlists

## Advanced geo features

Not built yet:
- radius filtering
- area-based filtering
- route-aware compare
- “nearest cheapest” logic

## Rich account system

Not built yet:
- avatars
- bios
- user pages
- follower/following

## Better photo pipeline

Possible future directions:
- server-side derivative generation
- multiple image sizes
- moderation-safe originals vs display derivatives
- photo-required submission rules
- photo-centric ranking, galleries, or evidence views

Currently the product is still operating on a lightweight client-compression model.
